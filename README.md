# বিদ্যালয় ম্যানেজমেন্ট সিস্টেম (Vidyalaya)

## 🆕 সর্বশেষ আপডেট (৩) — বড় আপডেট, Apps Script পরিবর্তনের দরকার নেই
এই আপডেটে **AppsScript-Code.gs ফাইলে কোনো পরিবর্তন লাগবে না** — এটি আগে থেকেই যেকোনো নতুন শীট/কলাম নিজে থেকে তৈরি করে নেয়। শুধু নতুন **index.html** ফাইলটা ব্যবহার করলেই হবে।

### নতুন কী যোগ হলো:
1. **Class History সাবমেনু** (Students মেনুতে) — কোনো ছাত্র Promotion Form দিয়ে ক্লাস পরিবর্তন করলে তার আগের ক্লাসের তথ্য (Student Class History শীটে) এখানে দেখা যাবে।
2. **Activation সাবমেনু** (Students মেনুতে) — নতুন **Activation Form**:
   - Student ID সিলেক্ট করলে Name/Class/Roll/Section/Subject/Session/Admission Date স্বয়ংক্রিয়ভাবে Promotion শীট থেকে লোড হবে।
   - Status থেকে **Deactivate** বা **Reactivate** করে Date দিয়ে সেভ করা যাবে (নতুন **Activation** শীটে সেভ হয়)।
   - Fee Invoice-এর হিসাবে এখন এই Deactivate/Reactivate সময়কাল বিবেচনা করা হয়: Admission → Deactivate এবং Reactivate → Invoice Date — এই দুই পিরিয়ডের হিসাব হবে, মাঝের বন্ধ থাকা সময়টুকু বাদ যাবে। (এককালীন খাত যেমন "Admission Fee"/"Registration Fee" এই হিসাবের বাইরে থাকবে, শুধু নিয়মিত/বার্ষিক খাতগুলো প্রোরেট হবে।)
3. **Office Information সাবমেনু** (Students মেনুতে) — Class ও Year সিলেক্ট করে Search করলে সেই ক্লাসের সব ছাত্রের ID, Name, Roll, Section, Guardian Name, Guardian Relation, Guardian Mobile No — টেবিল আকারে প্রিন্ট করা যাবে (উপরে প্রতিষ্ঠানের হেডিং + ক্লাস/বছর)।
4. **Fee Invoice** এখন সবসময় Promotion শীট থেকে ছাত্রের বর্তমান Class/Roll/Section লোড করে (আগের মতো Admission Form-এর পুরনো তথ্য থেকে না)। বছরভিত্তিক কোন ক্লাসে ছিল তা Class History শীট থেকে, আর Activation শীট চেক করে বাদ/যোগ হিসাব হয়।
5. **ID Card / Admit Card / Seat Plan** — এখন সবসময় Promotion শীট থেকে বর্তমান ক্লাস/রোল/সেকশন/সাবজেক্ট/সেশন লোড করে (প্রমোশনের পর কার্ডেও নতুন ক্লাস দেখাবে)।
6. **Admit Card** এখন **Landscape, Half A4** সাইজে প্রিন্ট হয় (আগে Portrait ছিল)।
7. **ID Card** ফুটার পরিবর্তন:
   - প্রতিষ্ঠানের **মোবাইল নাম্বার** এখন ফুটারে থাকবে (আগে Session-এর পরে বডিতে ছিল, সেটা সরানো হয়েছে)।
   - **QR Code** এখন ফুটারের **উপরে ডানপাশে** থাকবে।
   - প্রতিষ্ঠানের নাম বড় হলে ছোট ফন্টে **একলাইনে** এডজাস্ট হয়ে যাবে।
8. **মেনু এখন Accordion-style** — বাম/উপরের মেনুতে কোনো আইটেমে (যেমন Students, Teachers, Finance, Due List, Master Fee, All Card) ক্লিক করলে তার ভেতরের সব সেকশন/ট্যাব সাবমেনু হিসেবে খুলে যাবে, এবং সরাসরি সেই সেকশনে ক্লিক করে যাওয়া যাবে।

> **প্রোরেশন সম্পর্কে নোট:** Activation-ভিত্তিক হিসাব একটি ব্যবহারিক নিয়ম মেনে করা হয়েছে (দিনভিত্তিক সক্রিয়-সময়ের অনুপাতে খাত হিসাব করা)। আপনার প্রতিষ্ঠানের নিয়ম যদি এর চেয়ে ভিন্ন হয় (যেমন নির্দিষ্ট কিছু খাত প্রোরেট না করা), জানালে সহজেই সমন্বয় করে দেওয়া যাবে।

## 🆕 আগের আপডেট (২)
- **Google Sheet কলাম ফিক্স** — এখন প্রতিটা ফিল্ড (নাম, ক্লাস, রোল, ফোন ইত্যাদি) আলাদা কলামে সেভ হবে, একটাতে গাদাগাদি করে না।
- **Fee Invoice সম্পূর্ণ নতুন করে সাজানো** — "Open Fee Invoice Form" বাটনে চাপলে সার্চ ফর্ম আসবে; ID বা নাম দিয়ে ছাত্র খুঁজে সিলেক্ট করলে সব খাতের হিসাব একসাথে দেখাবে। প্রতিটা খাতে পেমেন্ট লিখে সবশেষে একবার **"Submit Payments"** চাপলেই সব সেভ হবে।
- **প্রিন্ট বাগ ফিক্স** — এখন Print বাটনে চাপলে শুধু সেই নির্দিষ্ট ডকুমেন্টটাই প্রিন্ট হবে, পুরো পেইজ বা পেছনের ফর্ম আর প্রিন্ট হবে না।

### ⚠️ Google Sheet কলাম ফিক্স করতে যা করবেন (একবারই):
1. নতুন **AppsScript-Code.gs** ফাইলটা ডাউনলোড করুন
2. আপনার Google Sheet-এ গিয়ে **Extensions → Apps Script**
3. আগের কোড পুরো মুছে নতুন কোডটা পেস্ট করুন
4. **Deploy → Manage deployments → ✏️ (Edit আইকন) → Version: "New version" → Deploy**
   (নতুন deployment বানাবেন না, পুরনোটাই "New version" দিয়ে আপডেট করলে URL অপরিবর্তিত থাকবে)
5. পুরনো ডেটা থাকলে সমস্যা নেই — নতুন কোড পুরনো ও নতুন দুই ধরনের শীট-ই পড়তে পারবে।

> **নোট:** `payments`-এর মতো ফিল্ড (একাধিক পেমেন্ট এন্ট্রি একসাথে থাকে) একটা কলামেই JSON আকারে থাকবে, কারণ একটা সেলে লিস্ট রাখার এটাই সহজ উপায়। বাকি সব সাধারণ ফিল্ড (নাম, ক্লাস, রোল, ফোন, ঠিকানা ইত্যাদি) প্রতিটা আলাদা কলামে থাকবে।

## 🆕 আগের আপডেট
- সাইডবারের বদলে এখন উপরে **মেনুবার** — মোবাইলে ৩ লাইনের (☰) আইকনে সব মেনু পাবেন
- Present ও Permanent — দুই ঠিকানাই যোগ করা হয়েছে (চাইলে "Same as present" টিক দিলে একই থাকবে)
- ছবি এখন শুধু বক্সে ক্লিক করে সিলেক্ট করবেন — কোনো লিংক লাগবে না
- Admission Form এখন **A4 সাইজে প্রিন্ট** করা যাবে
- Admission Form থেকে Total Fee/Paid Amount ফিল্ড বাদ দেওয়া হয়েছে — ফি এখন Master Fee থেকে নির্ধারিত হয়
- Master Fee-তে একসাথে একাধিক ফি-খাত (Fee Type + Amount) যোগ করা যাবে একটা ফর্মেই — Class ও Teacher দুই জায়গাতেই
- Admission Form-এ এখন সবার আগে **Student ID** (অটো-জেনারেটেড, যেমন `STU-2026-0001`) থাকে — এই ID দিয়ে সার্চ করে ছাত্রের তথ্য বের করা যাবে

## ফাইল
- **index.html** — পুরো অ্যাপটাই এই একটা ফাইলে। শুধু এটা ব্রাউজারে খুললেই চলবে।
- **AppsScript-Code.gs** — Google Sheet-কে ডেটাবেজ বানানোর কোড (Google-এ পেস্ট করতে হবে)।

আগে এটা দুইটা ফাইলে (index.html + app.js) ভাগ করা ছিল, যার কারণে সরাসরি ডাবল-ক্লিক করে খুললে **সাদা/খালি পেইজ** দেখাচ্ছিল — ব্রাউজার নিরাপত্তার কারণে local ফাইল থেকে ফাইল লোড আটকে দেয়। এখন সব একসাথে **index.html**-এ বসিয়ে দেওয়া হয়েছে, তাই এখন থেকে সরাসরি ওপেন করলেই কাজ করবে।

## সহজ সেটআপ (৩ ধাপ)

### ধাপ ১: Google Sheet ডেটাবেজ তৈরি করুন
1. [sheets.google.com](https://sheets.google.com)-এ গিয়ে একটা নতুন খালি Sheet খুলুন।
2. উপরে **Extensions → Apps Script**-এ ক্লিক করুন।
3. যা লেখা আছে সব মুছে, **AppsScript-Code.gs** ফাইলের পুরো কোডটা পেস্ট করে দিন।
4. **Deploy → New deployment** ক্লিক করুন:
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. **Deploy** চাপুন, পারমিশন দিন, তারপর যে URL-টা দেখাবে (শেষে `/exec` থাকবে) সেটা কপি করুন।

### ধাপ ২: URL-টা index.html-এ বসান
1. **index.html** ফাইলটা যেকোনো Text Editor (Notepad, VS Code ইত্যাদি) দিয়ে খুলুন।
2. `Ctrl+F` চেপে `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE` লেখাটা খুঁজুন।
3. এই লাইনটা পাবেন:
   ```js
   const DEFAULT_SHEETS_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
4. `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE` এর জায়গায় আপনার কপি করা URL-টা বসান, যেমন:
   ```js
   const DEFAULT_SHEETS_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
5. ফাইলটা সেভ করুন। ব্যাস, এখন **index.html** ডাবল-ক্লিক করে খুললেই ডেটা সরাসরি আপনার Google Sheet-এ সেভ হবে।

> চাইলে স্কুলের নামও একই জায়গায় বসাতে পারেন (`DEFAULT_SCHOOL_NAME` লাইনে) — এটা ID কার্ড, ইনভয়েসে দেখাবে।

### ধাপ ৩: ছবি/ডকুমেন্ট আপলোড (Token লাগবে না)
আগের ভার্সনে GitHub Token লাগত — এখন সেটা বাদ দেওয়া হয়েছে। এখন দুইভাবে ছবি যোগ করতে পারবেন:

**অপশন A — GitHub-এ নিজে আপলোড করে লিংক পেস্ট করুন:**
1. আপনার GitHub রিপোতে (github.com-এ গিয়ে) ছবি/ফাইলটা ম্যানুয়ালি আপলোড করুন (drag & drop)।
2. আপলোড হওয়া ফাইলে ক্লিক করে **Raw** বাটনে ক্লিক করুন — যে লিংকটা পাবেন সেটা কপি করুন।
3. অ্যাপের ছবি ফিল্ডে (Student/Teacher ফর্মে) সেই লিংকটা পেস্ট করে দিন।

**অপশন B — সরাসরি Embed করুন (GitHub-ই লাগবে না):**
1. ফর্মে **"Or embed a file"** বাটনে ক্লিক করুন।
2. আপনার কম্পিউটার থেকে ছবিটা সিলেক্ট করুন — এটা সরাসরি সেভ হয়ে যাবে, কোনো লিংকের দরকার নেই।

## নোট
- যদি Google Sheet URL না বসান, অ্যাপ **Offline Mode**-এ চলবে (ডেটা শুধু ওই মুহূর্তে থাকবে, পেইজ রিফ্রেশ করলে হারিয়ে যাবে)।
- সবাইকে এক জায়গা থেকে ব্যবহার করাতে চাইলে, এই **index.html** ফাইলটা GitHub Pages বা যেকোনো ফ্রি হোস্টিং-এ আপলোড করে দিতে পারেন — সবার ডেটা একই Google Sheet-এ জমা হবে।
